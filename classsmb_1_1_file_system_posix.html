Detailed Description

FileSystem adapter using the POSIX API. This is used on the desktop (Arduino Emulator) but can also be used on the ESP32 with the VFS mount point (e.g. "/sdcard" for SD_MMC).

Example: smb::FileSystemPosix files("/home/pi/share");
