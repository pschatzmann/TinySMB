Detailed Description

Client side of NTLMSSP (NTLMv2) wrapped in SPNEGO for the SMB2 SESSION_SETUP. If the server provides a timestamp, the AUTHENTICATE message contains a MIC and the final token a SPNEGO mechListMIC, as required by Windows and Samba.
