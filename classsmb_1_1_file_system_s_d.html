Detailed Description

template<class SDType, class FileType>
class smb::FileSystemSD< SDType, FileType >

FileSystem adapter for the Arduino SD library API (SD.open(path, mode), File::seek(), File::openNextFile() ...). It also works with SdFat style classes. The open modes can be adjusted if a library uses different flags.

Example: smb::FileSystemSD<SDClass, File> sd(SD);

Limitations of the Arduino SD API: no timestamps, files are renamed by copying and directories can not be renamed.
