Detailed Description

FileSystem adapter for the FatFs API of the arduino-fatfs library (https://github.com/pschatzmann/arduino-fatfs). It works with any of its drivers (SPI or SDMMC SD cards, RAM disks, disk images...) and supports timestamps, rename of files and directories, truncate and the free space.

Example: smb::FileSystemFatFs fat(*SD.getFatFs());

Timestamps of new and changed files are only set if FF_FS_NORTC is 0 and get_fattime() is provided. Names are converted with FF_CODE_PAGE: set FF_LFN_UNICODE to 2 (UTF-8) to support all characters.
