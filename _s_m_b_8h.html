Detailed Description

Header-only SMB2 (Windows file sharing) server and client for Arduino.

For SD card support include SMB_SD.h (SD library), SMB_SDMMC.h (SD_MMC library) or SMB_FatFs.h (arduino-fatfs library) instead.
